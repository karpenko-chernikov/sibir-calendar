# Календарь ХК Сибирь (КХЛ)

Подписка на матчи «Сибири» для **Apple Calendar** (Mac / iPhone) и **Google Calendar**.

Файл обновляется автоматически (примерно раз в 6 часов с Mac-синхронизации). Друзьям достаточно один раз добавить ссылку — дальше календарь подтягивается сам.

## Ссылка для подписки

```
https://raw.githubusercontent.com/karpenko-chernikov/sibir-calendar/main/sibir.ics
```

### Google Calendar

1. [calendar.google.com](https://calendar.google.com)
2. Слева **Другие календари** → **+** → **По URL**
3. Вставить ссылку выше → **Добавить календарь**

### Apple Calendar (Mac / iPhone)

- Mac: **Файл → Новая подписка на календарь…** → вставить ссылку
- iPhone: **Настройки → Календарь → Учётные записи → Другое → Добавить календарь с подпиской**
- Или открыть: `webcal://raw.githubusercontent.com/karpenko-chernikov/sibir-calendar/main/sibir.ics`

## Что внутри каждого матча

В сетке календаря — название и время (часовой пояс `Asia/Novosibirsk`).

В карточке / заметках события:

- дома / в гостях, город;
- форма текущей стадии (🟢 победа, 🔴 поражение, ⚪ ещё не сыграно) с соперником и счётом;
- все очные встречи сезона;
- статистика стадии **до этого матча**:
  - топ-3 бомбардиров / снайперов / ассистентов у нападающих и отдельно у защитников (для обеих команд);
  - % реализации большинства и % нейтрализации меньшинства.

Пока идёт регулярка — статистика по регулярке. Когда начнётся плей-офф — по текущему плей-офф.

## Для друзей

Можно просто переслать ссылку на `.ics` и инструкцию для Google/Apple выше. Отдельный файл скачивать не нужно: это подписка, она обновляется сама (у Google иногда с задержкой до нескольких часов).

## Обновление вручную

```bash
./scripts/auto-sync.sh
```
